# Astra site brush-up

The owner explicitly selected the entire site, requested Astra subagents, and
previously authorized validation followed by publication. The work is integrated
from the current main, preserving supplied artwork, story text, form data and
the mobile first-entry fixes. Parallel chats own Gallery, Exhibition/Tours,
Library/Search and Dream's paper stage; this checkout owns the final bundle.

| Area | Direction |

The legacy feature stylesheet order is retained. Astra's high-specificity,
route-scoped skins precede the legacy final cinematic/Mirage layers where their
contracts require it. The new shared sheet is static and introduces no canvas,
background worker, image, font, fullscreen blur or perpetual animation.

Integration review also traced a drag-time geometry sweep to the floating Ciel
button's collision search. That automatic search now waits while a rail owns
`data-rail-lock`, then reconciles once on release; suspended/hidden/unmounted
work is discarded. The rail's own gesture rules and performance threshold stay
unchanged.
WebKit's scroll-linked scale of the interactive rider console is also disabled:
bringing a pressed tab into view must not resize its hit box. Portraits,
selection lenses and the surrounding chapter choreography retain their motion.

## Verification record

tablet sizes and desktop widths. Integration checks use actual emitted
stylesheets, not temporary injected CSS. Browser results, final test/build
counts and the release identity are recorded by the integration turn; screenshots
and local browser diagnostics stay under `output/` and are not publication data.

touch moves at both 390px and 1280px (the existing limit remains two). WebKit's

unchanged 74px tab geometry and native scrolling. The shared menu's 36 links
were keyboard checked at five widths, including Escape focus restoration.
The integrated component test run passed 3,297 tests with five intentional
skips; types, 15 source-part groups and production build passed. Lint reported
zero errors and 32 existing warnings. Subsequent main-only content updates are
validated again before publication.

The final integrated health run passed 102/102 page-width checks (34 routes at
320/768/1440), with no horizontal overflow, broken images, duplicate IDs,
missing anchors, empty buttons, JS errors or subresource HTTP failures.

and Meta Unitas from World in the same document, with no crash or pageerror;
