# Astra site brush-up

The owner explicitly selected the entire site, requested Astra subagents, and
previously authorized validation followed by publication. The work is integrated
from the current main, preserving supplied artwork, story text, form data and
the mobile first-entry fixes. Parallel chats own Gallery, Exhibition/Tours,
Library/Search and Dream's paper stage; this checkout owns the final bundle.

## Visible changes

| Area | Direction |
| --- | --- |
| Shared launcher and chrome | Warm black and gold surfaces, clearer focus/current states, readable horizontal rider names and larger portrait tiles. Opaque status-bar chrome stays intact. |
| World | A broad warm-paper story spread between dark visual stages; more space for rider and character imagery; four-column cast directory on wide screens. |
| Dossiers | Clearer body measure, paragraph leading, heading rhythm and quiet figure surfaces. |
| Dream | A six-layer paper corridor and paper keys for chapter selection, plus a composed reading surface, chapter index and glossary typography. |
| Six rider special sites | Each work retains its own colour and hero/assembly engine; chapter text, mechanisms, finishers and comparisons gain stronger hierarchy. |
| Saga Cinema and Form Archive | Paper-like introduction/detail panels, stronger film identity and a refined wrapper around the unchanged archive frame. |
| Opening, downloads and missing records | More legible entry/replay controls and recovery/download surfaces. |

The legacy feature stylesheet order is retained. Astra's high-specificity,
route-scoped skins precede the legacy final cinematic/Mirage layers where their
contracts require it. The new shared sheet is static and introduces no canvas,
background worker, image, font, fullscreen blur or perpetual animation.

## Data repair discovered during integration

Main's Over Zetts Custom record declared `abilities` twice. The two original
arrays are now one array, retaining both the four-attribute abilities and armour
part descriptions. This fixes the duplicate-key type error and the silent
overwriting of the first list. Source-parts remain synchronized.

## Verification record

Component owners validated their regions at 320px, 390px, portrait/landscape
tablet sizes and desktop widths. Integration checks use actual emitted
stylesheets, not temporary injected CSS. Browser results, final test/build
counts and the release identity are recorded by the integration turn; screenshots
and local browser diagnostics stay under `output/` and are not publication data.

Publication follows `docs/production-release.md`. Gallery checks are read-only;
no sample artwork is posted and no public title or user setting is changed.
Physical iPhone/iPad behaviour remains distinct from desktop WebKit emulation.
