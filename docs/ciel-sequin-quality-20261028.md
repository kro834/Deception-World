# 炎の後のスパンコール：金属と反転の改善

表面を12角の薄い板から、前後の面・浅い皿状成形・丸いベベル・側壁を持つ閉じた形状へ変更した。粗いポインターでは16角・130共有頂点、通常は24角・194共有頂点。インスタンス描画は1 drawのまま。端末ごとの枚数・描画解像度上限は変更しない。

最初の比較で縦のチェーン状に見えたため、正方格子から千鳥状の六角配置へ改めた。最小間隔は通常14px・粗いポインター16px、行間はその√3/2倍。半径は間隔の0.63倍とし、16角の裏面とベベルの寸法を考慮しても写真が全面を覆うようにした。834×1194の粗いポインターでは4,752枚、1440×900の通常ポインターでは7,904枚。描画・なぞる判定・軽量表示・回転時の状態復元は同じ中心座標を使う。

金属面は異方性GGXと微細な磨き目、実形状の法線、柔らかい照明の反射で描く。写真面は明示した裏面属性で判別し、金属の色調やピン・暗い縁を重ねずに表示する。裏返した写真の連続した画面座標UV、cover/containと原画自体は変更しない。

写真側の着座直前だけ、縁にも同じ画面座標の写真を滑らかに回り込ませる。全反転時に隣の縁が写真を隠して黒点になる問題を抑え、表側と主要な反転区間では金属の側壁を保つ。

Blender 4.5.9 LTSのCycles CPUで、暗い室内と面発光のソフトボックス、床への間接反射を768×384のパノラマに実レンダリングした（96 samples、seed 28）。Three.jsは5,590バイトのWebPを追加の反射素材として使用する。これは制作時のレンダリングであり、端末でBlenderやレイトレーシングを実行するものではない。

- 再制作: `scripts/blender/ciel_sequin_studio.py` をBlenderで実行し、`scripts/build-ciel-sequin-studio.mjs --source=studio.png` で梱包する。
- 検査: `node scripts/build-ciel-sequin-studio.mjs --check`。シーンと配信素材のSHA-256・寸法・容量・メタデータを確認する。
- `.blend`、元PNGとブラウザー証跡はプロジェクト隣の `handoff/ciel-sequin-quality-20261028/` に保存する。配信素材には人物の原画を含めない。

指先の光は短い指数補間で追従し、なぞった線の中心から外縁へ最大65msの時間差で反転が伝わる。反転途中の逆なでは現在の角度と速度から再開する。各片のバネはシェーダーで解析的に評価し、動きが収まれば描画を停止する。

反射素材の取得は炎後の黒画面が終わった後だけ。読み込みに失敗した場合はシェーダー内の簡易照明を維持し、画像・操作を止めない。省エネ・動きを減らす設定では反射素材を取得せず、既存のCanvas2D表示を使う。コンテキスト消失、破棄後の遅延応答、再表示、iOSの端タッチ対策も維持する。

専用テストは閉じた形状・外向き面・法線・描画予算・揺れ・逆方向操作・光の停止・反射素材の失敗と破棄を検査する。全体3,459成功・既存6スキップ、最後のシェーダー調整後は関連31テスト、型検査、本番ビルド、15 source-parts整合が成功。lintは既存32警告・エラー0。実機iPadの動作確認は含まない。
