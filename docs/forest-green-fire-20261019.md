# 炎のフォレストグリーン統一（2026-10-19）

オーナー指定により、オープニングと RISING THE WORLD の炎、燃焼縁、火の粉、煙・装甲への照り返し、熱による発光とダイブの橙色光を緑系へ変更した。基準色は ForestGreen（#228b22）。暗部から淡い緑の高温部までの階調を保ち、炎の形・動作・時刻・品質段階は変更していない。

WebGL と CSS の両経路に適用し、軽量表示用の炎・燃焼縁・煙など10点を既存の生成スクリプトで再生成。RE DIVE は共用する燃焼素材、火の粉、照り返しと遷移光を揃え、機密資料の文章・信号の状態色は維持した。元の作品画像、ロゴの配色、日本語フォント、レクソナンスの入場コールには変更なし。

ゲートの白文字はコントラスト基準を維持するためグラデーション下部を濃くした。既存テストの更新はオーナー指定で変わった突破光の色の pin のみ（理由コメント付き）。点滅、性能、モーション、アクセシビリティの閾値は変更なし。

`npm test` は2513件中2508成功・失敗0・既存スキップ5。型検査・ESLint（既存警告12件）・15ソースグループ同期・本番ビルドが成功。オープニングのスマホ／PC、WebGL／CSS の各434フレーム点滅検証では一般点滅最大1回/秒、赤色点滅0回。ライジングは同じ4条件の再生・品質段階・点滅・RE DIVE 検証が成功し、警告0件。一般点滅最大1回/秒、赤色点滅0回。実機Safariは未確認。
