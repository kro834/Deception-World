# 近未来映画サイトのデザイン監査と改修

## 方針と公開範囲

既存の人物設定、数値、原画、ロゴ、ルートを維持したまま、作品画が中心になる近未来映画サイトへ整理した。Sitesの設計・可読性の手順を既存のVite/TanStack構成へ適用し、新しいサイトへの移植は行っていない。公開はユーザー指定どおりGitHubのmainへの反映のみで、Grok側の公開状態や別のSites作品は変更しない。

## 画像による検討

内蔵の画像生成を使い、全体案を3回、Dream専用案を2回検討した。最初の映画パンフレット調から、暗いネイビー、アイボリーの文字、シアンと少量の朱色、角張った英文見出しへ改良した。Dreamは既存の神社・竹林の画に、金色の門型罫線、朱の操作面、薄い青紫の軌道を組み合わせる方向に修正した。

生成案にはスマートフォンの縦横比の誤差、架空の小見出し、ポスター下部の切れがあったため、完成画像をそのままWebへ埋め込んではいない。実装は既存画像と実テキストを使い、390×844、1194×834、1024×768の実ブラウザーで再検証する。顔と文字を重ねないこと、ポスター操作を画像の外へ置くこと、意味のない情報パネルを増やさないことを優先した。

## 実装

`styles-cinematic-edition.css` を各ルートの最後に読み込ませ、共通の色・罫線・操作面を管理する。特設サイトは専用CSSの後にこのレイヤーを読み込むため、旧スタイルの再読込によって新デザインが戻らない。CSSはルート単位のURL配信を維持し、開始ページへ全スタイルを一括追加していない。

WorldのiPhoneヘッダーは3つのナビとメニューボタンを同時に表示し、古い二列gridの強制指定との競合を解消した。ポスターを小型化し、通常サイズの390×844では見出しとENTER THE WORLDを最初の画面内に置いた。文字拡大で固定ヘッダーが高くなる場合は既存のResizeObserverを再利用して上余白を追従させる。明るいSTORY面へ白文字が継承される競合も除去し、見出しのコントラスト比を7:1以上で検証する。

サイドメニューと人物資料は、不透明に近い操作面、一定の行間、細い区切りで統一した。レクソナンス／エクスプリームの横iPadはコピーと人物画を別の列へ配置し、以前の絶対位置用translateが残って画像を画面外へ押し出さないようにしている。

Dreamは既存のロゴ周辺へblurを追加せず、共有の省負荷スタイルが親へblurを復活させる競合も解消した。横iPadのポスター欄は原画と8つのサムネイルを並べ、下に3つの操作を置く。人物資料は画像と本文を二列にし、iPhoneは縦積みを維持する。装飾はCSSの静的な線とグラデーションが中心で、追加の常時アニメーションや画像ダウンロードはない。文字の光学スキャンは既存の一度きりのopacity/transformアニメーションを使用する。

フォームアーカイブはiframe内も調査し、iPhoneの「フォーム一覧」「閉じる」が件数表示に押されて縦折れする問題だけを修正した。件数は別行で残し、比較値や判定には触れていない。CSSとiframe URLのキャッシュ版をr47へ更新した。監査時のscrollIntoViewがoverflow:hiddenの比較カードを内部スクロールする現象は、通常の指スクロールで再現しない検査上の誤検知と判明したため、比較ロジックは変更していない。

## 回帰検証

次のコマンドはリポジトリ直下、かつ最新ビルドを起動し直したpreviewに対して実行する。SSRサーバーは古いアセット一覧を保持するため、build後の再起動が必要である。

```sh
env -u DATABASE_URL APPLY_DESTRUCTIVE_MIGRATIONS=0 npm run release:build
node scripts/sync-source-parts.mjs --check
npm run preview
BASE_URL=http://localhost:8082 node scripts/verify-cinematic-edition.mjs
BASE_URL=http://localhost:8082 node scripts/verify-anime-ui.mjs
BASE_URL=http://localhost:8082 node scripts/verify-scroll-surfaces.mjs
BASE_URL=http://localhost:8082 node scripts/verify-modal-scroll.mjs
```

`verify-cinematic-edition.mjs` はナビの遮蔽、CTA位置、STORY見出しのコントラスト、Dreamポスター・資料の配置、横iPadでの特設人物画のはみ出し、200%文字拡大時の横溢れを検証する。`PW_ENGINE=webkit` でWebKitも選択できる。実機のiOSバージョンやGPU発熱の試験ではなく、ブラウザーエンジンとビューポートの検証である。

既存の操作検証には、375×667・1376×1008・393×851でのEPスワイプ、コラムのタップ／長押し／ドラッグ、メニューのキーボード操作、ダイアログを閉じた後の復帰が含まれる。横iPadのDreamは意図的な二列化なので、旧「1180px以下は一列」条件を、右列に8つのサムネイルが存在し、ポスターと重ならず枠内に収まる条件へ更新した。タッチレールの寸法や長押し閾値は変更していない。

最終結果は、npm test 375件、typecheck、lint、buildが成功した。lintは既存警告11件のみでエラーはない。ChromeとWebKitの各12画面で通常表示・200%文字拡大の検証を通過し、既存操作検証は35/35、タッチスクロールは67/67、モーダルの背景ロック・閉じた後の復帰は両画面サイズで成功した。全24ルート×2サイズの読み込み監査では横溢れ、JavaScript例外、画像読込失敗を検出していない。フォーム比較はSaga/Realmを両サイズで確認し、数値の変更なしに見出しと閉じる操作が改善された。

ビルド後にだけ現れたChromeのロゴ背景問題は、vendor-prefixed宣言を標準宣言より後へ書くと圧縮後に標準のbackdrop-filter解除が消えることまで切り分け、prefix→標準の順序へ統一した。ソースの文字列検査だけでは見落とすため、実ブラウザーでロゴ親のcomputed backdrop-filterがnoneになる回帰チェックも追加した。生成時の完全なプロンプトは `cinematic-image-prompts-20260921.md` に保存している。
