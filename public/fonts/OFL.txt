Fonts in this folder

rexonance-forge-20261016.woff2 ("Rexonance Forge")
  A subset (U+0020-007E, U+00B7, U+00D7, U+2212; width 125) of Saira,
  designed by Omnibus-Type.
  Copyright 2020 The Saira Project Authors (https://github.com/Omnibus-Type/Saira)

rexonance-forge-outline-20261016.woff2 ("Rexonance Forge Outline")
  The same Saira subset instanced at weight 800 with its overlapping
  contours merged (fontTools instancer, OverlapMode.REMOVE), holding only
  the letters of the outlined name and form codes, so an outline never
  shows a contour inside a letter.

rexonance-etch-20261016.woff2 ("Rexonance Etch")
  A subset (a-z and !) of Michroma, designed by Vernon Adams.
  Copyright 2011 The Michroma Project Authors (https://github.com/googlefonts/Michroma-font)

All three are modified (subsetted) versions. Each carries its own name, in
its name table (family, full and PostScript names) and in CSS: "Rexonance
Forge", "Rexonance Forge Outline" and "Rexonance Etch". Neither copyright
statement declares a Reserved Font Name. All are licensed under the SIL
Open Font License, Version 1.1, copied below.

rexonance-mincho-display-first-20261021.woff2 ("Rexonance Mincho", CSS alias)
rexonance-mincho-display-20261021.woff2 ("Rexonance Mincho", CSS alias)
rexonance-mincho-text-first-20261021.woff2 ("Rexonance Mincho Text", CSS alias)
rexonance-mincho-text-20261021.woff2 ("Rexonance Mincho Text", CSS alias)
  Subsets of Shippori Mincho B1 ExtraBold (800: display) and Medium (500:
  text), designed by FONTDASU, holding only the glyphs the Rexonance page
  prints in them: the -first files the first screen's (the hero's line,
  lede and scroll cue, the bar's name), the others the rest of the page's
  titles and ledes, with the digits (fontTools subsetter, palt kept,
  unhinted; the copy is read by scripts/rexonance-type-copy.mjs).
  Copyright 2021 The Shippori Mincho Project Authors
  (https://github.com/fontdasu/ShipporiMincho). No Reserved Font Name;
  the name tables are unchanged. License: rexonance-mincho-OFL.txt (the
  same SIL Open Font License, Version 1.1).
